1. **Stripe webhooks never verified** (#62): the JSON parser ran in front of `constructEvent`, so every
   billing event got 400. Fixed and pinned by a test that fails on the old list.
2. **Client-portal users could read the books** (#62): confirmed with a request before fixing.
3. **Password hashes in firm/admin member lists** (#62): `/api/firm/clients/:id/summary` and
   `/api/admin/clients/:id` returned full user rows.
4. **Stripe retries skipped after a failed delivery** (#62).
5. **Quarterly filers blocked by the month-end checklist every month** (#66).
6. **Payment chasing ignored credit notes** (#61), contrary to the one-settlement-rule platform rule.
7. **Entertainment VAT recovered on expense claims** (#61), contrary to Art. 53.

### Summary of gaps

Missing:

- Row 12: month-end checklist does not accept a quarterly VAT return (or a draft). Small.
- Row 13: a period lock blocks generating the VAT return draft. Small for drafts; large for submit under a lock.
- Row 16: no "Filed outside Muhasib" for historical VAT periods. Large.
- Row 19: no leave-pay provision (2037 / 5029), opening leave or catch-up. Large.
- Row 24: no employee loans. Large; this is a feature.
- Row 34: a credit card cannot be a liability bank account. Small to borderline.

Partially:

- Row 7: no UI to create a vendor debit note with product lines; the server is done. Large.
- Row 10: no cancel-refund path and no refund UI for customer credits. Large.
- Row 17: employee role can still read the GL and other finance records; no HR self-service login scope. Large, product decision.
- Row 23: final settlement has no maker-checker approval. Large.
- Row 25: no per-run payroll register with tie-out. Large.
- Row 27: no UTC process-timezone pin while dates are `timestamp` columns. Small.
- Row 30: foreign-currency bank reconciliation runs in base currency. Large, about 50-80 lines.
- Row 31: an asset cannot be linked to an existing journal. Large.
- Row 33: a closed-year historical asset is refused instead of registered with catch-up. Large, overlaps row 31.
- Row 35: customer credit balances are not shown on the A/R ageing or balances screens. Small.

Design differences that are not gaps: row 3 (a void in a locked or filed period is refused instead of moved to the
next open day), row 15 (books start is derived, not a setting) and row 21 (calendar-day proration instead of a
30-day month).
