[Projects](/projects) lets you see what a job earns and costs.

## Set up a project

1. Choose **New project** and pick the customer.
2. Add tasks if you want to split the work.
3. Set a billing rate if you charge by the hour.

## Log time and costs

Add time entries with the date, hours and a note. Link expenses to the project so its costs are complete.

## Invoice the work

Open the project and create an invoice from the **unbilled** time and costs. Each entry is marked as billed, so nothing is invoiced twice.

## Profitability

The project page compares what you billed with the cost of time and expenses.

## Good to know

- Billed entries are locked. Correct them with a credit note on the invoice.
- Project invoices follow the same VAT and posting rules as any other invoice.
